SkillHub
Система управления учебной деятельностью

1. Общая информация
SkillHub — веб-приложение для управления учебным процессом. Система предназначена для администрирования курсов, пользователей, уроков, заданий, записей студентов и выдачи сертификатов.

Проект разработан в рамках лабораторной работы с использованием современных технологий экосистемы Spring.

2. Цель проекта
Целью разработки является создание полнофункционального веб-сервиса, удовлетворяющего следующим требованиям:

1)наличие не менее 7 сущностей со связями между ними

2)реализация CRUD-операций

3)ролевая аутентификация и авторизация

4)использование SQL базы данных

5)применение системы миграций

6)покрытие кода тестами не менее 70%

7)подключение мониторинга и логирования

3. Архитектура приложения
Приложение реализовано по трёхслойной архитектуре:

Controller → Service → Repository → Database

Controller — обработка HTTP-запросов.
Service — реализация бизнес-логики.
Repository — взаимодействие с базой данных через Spring Data JPA.

Архитектура разделяет ответственность и обеспечивает масштабируемость и поддерживаемость кода.

6. Модель данных
В проекте реализовано 8 сущностей:

Role,
Course,
Lesson,
Assignment,
Submission,
Enrollment,
Certificate.
Связи между сущностями реализованы через:

@ManyToMany
Модель отражает структуру учебного процесса.

6. Реализованный функционал
6.1 CRUD-операции
Для всех сущностей реализованы операции:

Create
Read
Update
Delete
Контроллеры обеспечивают полный набор CRUD-методов.

6.2 Авторизация и безопасность
В системе реализована ролевая модель доступа:

STUDENT
TEACHER
ADMIN
Используется Spring Security.
Доступ к API ограничивается в зависимости от роли пользователя.
Применяется HTTP Basic аутентификация.
